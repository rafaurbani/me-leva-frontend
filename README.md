# Me Leva - Frontend

## Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- Um gerenciador de pacotes (npm, yarn ou pnpm)

## Instalação

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/rafaurbani/me-leva-frontend.git
   cd me-leva-frontend
   ```

2. **Instale as dependências:**

   ```bash
   npm install
   ```

## Rodando Localmente

Para iniciar o servidor de desenvolvimento e rodar o projeto na sua máquina:

```bash
npm run dev
```

Após rodar o comando, o terminal mostrará o link local. Acesse esse link no seu navegador para ver a aplicação.
